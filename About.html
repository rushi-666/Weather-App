Weather information, brought together in one simple experience

Atmosphere is a weather platform designed to turn complex weather data into clear, useful information. From current conditions and forecasts to air quality, radar, and activity recommendations, Atmosphere helps users understand what is happening around them.

From a City Name to Weather Data

When a user searches for a city, Atmosphere first converts the city name into geographical coordinates. These latitude and longitude values are then used to request weather information for that exact location.

Weather Around You

Atmosphere can use the browser's location service to determine the user's current latitude and longitude. These coordinates are used to retrieve local weather data and identify the corresponding location.

Turning Location Data into Weather Information

Atmosphere uses the Open-Meteo Weather API to retrieve weather information for a selected location. After obtaining the latitude and longitude of a location, the application sends these coordinates to the weather API and receives data such as temperature, humidity, wind speed, precipitation, weather conditions, and forecast information.

Converting a City Name into Coordinates

When a user searches for a city, Atmosphere uses geocoding to convert the entered city name into geographical coordinates. The resulting latitude and longitude identify the location precisely and are then used to request weather and other location-based information.

Finding a Location from Your Coordinates

When a user chooses their current location, Atmosphere uses the browser's geolocation capability to obtain latitude and longitude. These coordinates are then processed through reverse geocoding to identify the corresponding city or location name, allowing Atmosphere to display weather information for the user's current area.

Understanding the Air Around You

Atmosphere also provides air-quality information for the selected location. The application retrieves environmental data and presents important air-quality indicators such as AQI, PM2.5, and PM10, helping users understand the quality of the air in their area.

Visualizing Weather on an Interactive Map

Atmosphere uses Leaflet to provide interactive maps and integrates RainViewer radar data to visualize precipitation and weather movement. This allows users to explore weather conditions geographically instead of relying only on numerical information.

Weather Information Across Different Time Scales

Atmosphere organizes weather information into different forecast views to help users understand both current and upcoming conditions. Users can explore Today, Hourly, 10-Day, MinuteCast, and Monthly weather information according to the level of detail they need.

Weather-Based Activity Recommendations

Atmosphere goes beyond displaying weather conditions by using environmental information to provide recommendations for outdoor activities. The application evaluates factors such as temperature, precipitation, wind, air quality, and other conditions to determine how suitable the weather is for activities such as running, cycling, golf, swimming, yoga, and gardening.

Turning Weather Data into Everyday Decisions

Atmosphere converts weather conditions into practical recommendations that users can apply in their daily lives. Based on the current environmental conditions, the application provides suggestions such as what to wear, sun protection, and the best time for outdoor activities.

Built with Modern Web Technologies

Atmosphere is built using a combination of web technologies and external data services. HTML and CSS provide the structure and visual design, while JavaScript handles application logic and API communication. Bootstrap is used for responsive interface components, while services such as Open-Meteo, Leaflet, RainViewer, geocoding, reverse geocoding, and browser geolocation provide the data and functionality behind the application.
