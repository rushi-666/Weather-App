# Atmosphere – Weather Forecasting Web Application

Atmosphere is a modern weather forecasting web application that provides real-time weather information, forecasts, air quality, weather radar, warnings, and weather-based activity recommendations.

# Features

-  Current weather information
-  Celsius / Fahrenheit temperature switching
-  Hourly weather forecast
-  10-day weather forecast
-  MinuteCast precipitation forecast
-  Monthly weather information
-  Interactive weather radar
-  Air quality information
-  Weather warnings
-  Weather-based activity recommendations
-  Current location detection
-  City search
-  Responsive design

# Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Leaflet.js
- Chart.js
- Open-Meteo API
- RainViewer
- OpenStreetMap / Nominatim
- Browser Geolocation API
- Local Storage

## 📂 Project

Atmosphere combines weather APIs, interactive maps, charts, and location services into a single weather forecasting application.
